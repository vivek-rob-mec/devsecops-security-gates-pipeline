# Standards Mapping

This is a **conceptual mapping**, not a formal compliance certification.

| Repository capability | NIST SSDF theme | OWASP / ASVS theme | SLSA theme |
| --- | --- | --- | --- |
| Security requirements / training / process | PO | Verification planning | — |
| Source and artifact protection | PS | Secure build/deploy controls | Source/build integrity |
| Threat modeling / secure design | PW | Architecture requirements | — |
| SAST / SCA / tests | PW | Verification requirements | Dependency/source assurance |
| SBOM / provenance / signing | PS/PW | Component/deployment assurance | Provenance/build assurance |
| Vulnerability response | RV | Defect remediation | — |

Formal compliance requires interpreting the authoritative standard and organization-specific evidence requirements.
