# NIST Secure Software Development Framework (SSDF)

NIST SP 800-218 SSDF v1.1 provides high-level secure-development practices that can be integrated into SDLC implementations.

The four practice groups are:

- Prepare the Organization (PO)
- Protect the Software (PS)
- Produce Well-Secured Software (PW)
- Respond to Vulnerabilities (RV)

Official publication: <https://csrc.nist.gov/pubs/sp/800/218/final>
