# DevSecOps Overview

## DevOps vs DevSecOps

A DevOps pipeline optimizes reliable software delivery. DevSecOps preserves that delivery model while making security requirements, automation, evidence, and release policy part of normal engineering work.

### Shift left

Controls applied early include:

- secure requirements;
- threat modeling;
- secure coding standards;
- pre-commit/PR secret scanning;
- SAST;
- SCA;
- IaC/configuration scanning.

### Shift right

Controls applied after build/deployment include:

- staging DAST and API testing;
- admission control;
- runtime workload security;
- EDR/SIEM/telemetry;
- vulnerability management;
- incident response;
- feedback into backlog and standards.

Neither direction replaces the other.
