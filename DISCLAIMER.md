# Disclaimer

This repository is intended for **education, defensive security engineering, and explicitly authorized security testing**.

Security scanners—especially active DAST tools—can generate significant traffic, alter application state, trigger defenses, or expose sensitive findings. Run them only against systems for which you have permission and preferably in controlled staging/test environments.

Example severity thresholds, remediation SLAs, exception expiry periods, and approval models are reference policies. They must be adapted to your organization's legal, regulatory, operational, and risk-management requirements.
