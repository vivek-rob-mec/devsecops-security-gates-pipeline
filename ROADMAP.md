# Roadmap

## v1 — Foundation

- Secure SDLC, SAST, SCA, DAST, secret scanning, IaC security.
- Reference pipeline and security-gate policy.

## v2 — Software supply chain

- Richer SBOM examples, artifact attestations, signing, provenance verification.
- Dependency update automation patterns.

## v3 — Kubernetes enforcement

- Kyverno / OPA Gatekeeper admission examples.
- Signed-image verification and least-privilege deployment controls.

## v4 — Runtime security

- Falco/Tetragon examples, SIEM integration patterns, incident-response workflows.

## v5 — Governance and metrics

- Risk dashboards, MTTR/age metrics, release evidence automation, compliance mappings.
